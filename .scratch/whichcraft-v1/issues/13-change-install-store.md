# 13: เปลี่ยนที่เก็บการติดตั้ง

**What to build:** ผู้ใช้เปลี่ยนที่เก็บการติดตั้งในหน้าตั้งค่าได้ การติดตั้งใหม่จะไปลงที่เก็บใหม่ ส่วนการติดตั้งในที่เก็บเดิมยังแสดงอยู่และยังเป็นของแอป

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] การติดตั้งที่แอปจัดการแต่ละชุดบันทึกที่เก็บของตัวเองไว้
- [ ] ติดตั้งที่ A แล้วเปลี่ยนเป็น B ต้องเห็นการติดตั้งทั้งใน A และ B (S-1)
- [ ] การดูรายการเรียก mise ด้วยโฟลเดอร์ข้อมูลของแต่ละที่เก็บ
- [ ] ไม่ย้ายการติดตั้งเดิมตามไปที่เก็บใหม่ (Q17)
- [ ] มี test ที่ core ด้วยของปลอม และมี adapter contract test กับ mise จริงในที่เก็บสองที่
