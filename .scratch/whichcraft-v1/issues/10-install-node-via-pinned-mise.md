# 10: ติดตั้ง Node ผ่าน mise ที่ pin ไว้

**What to build:** ผู้ใช้เปิดรายการเวอร์ชันของ Node ที่ติดตั้งได้ เห็นขนาดดาวน์โหลด แล้วกดติดตั้ง ครั้งแรกแอปเลือกที่เก็บการติดตั้ง แจ้งขนาด แล้วโหลด mise เวอร์ชันที่ pin ไว้มาตรวจ hash ก่อนใช้ Node ที่ติดตั้งแล้วแสดงเป็นการติดตั้งที่แอปจัดการ แต่ยังไม่แตะ PATH จนกว่าผู้ใช้จะเลือก ใบนี้เป็นเส้นทางแรกของ ToolManager

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] ครั้งแรกถามที่เก็บการติดตั้ง ค่าเริ่มต้นคือ `%LOCALAPPDATA%\Whichcraft\installs` (I-5)
- [ ] โหลด mise เวอร์ชันที่ pin ไว้ ตรวจ SHA256 กับค่าที่ฝังในแอป แล้วเก็บที่ `%LOCALAPPDATA%\Whichcraft\mise\<version>\` (I-10) ถ้า hash ไม่ตรงให้ลบทิ้งและหยุด (I-11)
- [ ] ถ้าออฟไลน์หรือโหลดไม่ได้ ให้แจ้ง โดยการค้นหา สลับ Apply และ Undo ยังใช้ได้ (I-12) และ installer ของแอปไม่มี mise อยู่ข้างใน (I-13)
- [ ] ทุกคำสั่ง mise ใช้ dir แยกทั้ง 5 ตัว และไม่อ่านหรือแก้ config ของ mise ที่ผู้ใช้ติดตั้งเอง (I-6) ใช้แค่ `install`, `ls --json` และ `ls-remote --json`
- [ ] ติดตั้งแล้วไม่เขียน PATH, registry หรือ config ใด ๆ (I-7) และ Node รันได้จากโฟลเดอร์เวอร์ชันจริง (I-1)
- [ ] แสดงขนาดก่อนติดตั้ง (I-9) ถ้าล้มเหลวหรือยกเลิกจะไม่มีไฟล์ค้างในที่เก็บ (I-8)
- [ ] เลือก Node ที่ติดตั้งแล้วเป็นค่าเริ่มต้นได้ด้วยแผนเดียวกับใบที่ 03
- [ ] มี test ที่ core ด้วยของปลอม (รวม hash ไม่ตรงและออฟไลน์) และมี adapter contract test ของ ToolManager กับ mise จริงในที่เก็บแยก
