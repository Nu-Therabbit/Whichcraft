# 14: ถอนการติดตั้งที่แอปจัดการ

**What to build:** ผู้ใช้ถอนการติดตั้งที่แอปจัดการได้ในคลิกเดียว ถ้าเป็นตัวที่ใช้อยู่ แอปให้เลือกตัวแทนแล้วสลับให้ก่อน ถ้ามีโปรแกรมใช้การติดตั้งนั้นอยู่ (java, Gradle daemon หรือ Terminal ที่ cd ค้างอยู่) แอปแสดงรายชื่อและไม่ให้ถอน ใบนี้สร้าง UsageProbe และขั้นตอนเลือกตัวแทน ซึ่งใบที่ 15 ใช้ต่อ

**Blocked by:** 03, 10

**Status:** ready-for-agent

- [ ] ถอนผ่าน mise ด้วยที่เก็บของการติดตั้งนั้น แล้วโฟลเดอร์ cache และ junction หายครบ (R-1) รวมถึงการติดตั้งในที่เก็บเก่า (S-2)
- [ ] ถ้าเป็นการเลือกหรือการติดตั้งที่มีผลจริง ต้องเลือกตัวแทนก่อน แล้ว Apply การสลับก่อนจึงถอน (R-12)
- [ ] UsageProbe ตรวจด้วย Restart Manager กับไฟล์หลัก ร่วมกับดูพาธของ exe และลองเปลี่ยนชื่อโฟลเดอร์ไปและกลับ
- [ ] ถ้ามี java หรือ Gradle daemon ใช้อยู่ แสดงชื่อโปรแกรม แนะนำ `gradlew --stop` และไม่ kill เอง (R-10)
- [ ] ถ้ามี Terminal ที่ cd ค้างอยู่ แจ้งว่ามีโปรแกรมเปิดโฟลเดอร์อยู่และไม่ให้ถอน (R-11)
- [ ] ขั้นตอนถอนบันทึกลง Journal
- [ ] มี test ที่ core ด้วยของปลอม (รวมการ rename ที่ถูกล็อก) และมี adapter contract test ของ UsageProbe บน Windows จริงตามแบบงานพิสูจน์ข้อ 7
