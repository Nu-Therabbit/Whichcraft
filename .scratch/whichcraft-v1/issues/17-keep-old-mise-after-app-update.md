# 17: ใช้ mise ตัวเก่าต่อหลังอัปเดต Whichcraft

**What to build:** หลังผู้ใช้อัปเดต Whichcraft เป็นรุ่นที่ pin mise เวอร์ชันใหม่ ผู้ใช้ยังถอนและดูรายการการติดตั้งเดิมได้แม้ออฟไลน์ เมื่อต่อเน็ตแล้ว แอปโหลด mise ตัวใหม่เบื้องหลัง ตรวจ hash แล้วลบตัวเก่า

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] เปิดแอปครั้งแรกหลังอัปเดต ถ้ามีการติดตั้งที่แอปจัดการอยู่ ให้เริ่มโหลด mise ตัวใหม่เบื้องหลังทันที
- [ ] ระหว่างที่ยังไม่มีตัวใหม่ ใช้ตัวเก่าได้เฉพาะถอนและดูรายการ ส่วนปุ่มติดตั้งแจ้งให้รอ (I-15)
- [ ] เมื่อตัวใหม่ตรวจ hash ผ่านแล้วจึงลบตัวเก่า
- [ ] การติดตั้งที่ทำด้วยตัวเก่ายังเห็นและถอนได้ด้วยตัวใหม่ (I-14)
- [ ] มี test ที่ core ด้วยของปลอมที่จำลองการเปลี่ยนเวอร์ชันของ mise และมี adapter contract test ที่ติดตั้งด้วย mise เวอร์ชันหนึ่งแล้วถอนด้วยอีกเวอร์ชัน
