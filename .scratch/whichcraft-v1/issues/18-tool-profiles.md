# 18: โปรไฟล์ — สร้าง Apply และสถานะว่าตรงหรือไม่

**What to build:** ผู้ใช้สร้างโปรไฟล์เครื่องมือที่ตั้งชื่อได้และระบุแค่บางเครื่องมือ แล้ว Apply ได้ในครั้งเดียว เครื่องมือที่ไม่ได้ระบุคงค่าเดิม ถ้ามีตัวใดใช้งานไม่ได้ แอปจะไม่ Apply เลย หน้ารายการโปรไฟล์บอกว่าแต่ละโปรไฟล์ตรงกับการติดตั้งที่มีผลจริงหรือไม่

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Apply โปรไฟล์ A (Java 17 + Node 20) แล้ว Apply B (Java 21 อย่างเดียว) ผลคือ Java 21 และ Node 20 (F-1)
- [ ] ถ้ามีการติดตั้งตัวใดใช้งานไม่ได้ ไม่เขียนอะไรเลยและแสดงรายการที่ต้องแก้ (F-2)
- [ ] โปรไฟล์อ้างถึงด้วยผู้จำหน่าย + เวอร์ชันเต็ม และใช้รากการติดตั้งที่จำไว้ก่อนเมื่อมีหลายชุด (F-4)
- [ ] ไม่มีสถานะ "โปรไฟล์ที่ใช้อยู่" แต่ละโปรไฟล์แสดงว่าตรงหรือไม่ และอัปเดตเมื่อ environment ถูกแก้จากนอกแอป (F-6)
- [ ] Apply โปรไฟล์ใช้แผน, UAC, Journal และ Undo เดียวกับการเลือกทีละเครื่องมือ
- [ ] มี test ที่ core ด้วยของปลอม
