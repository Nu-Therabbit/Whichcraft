# 04: Undo ที่ย้อนเฉพาะสิ่งที่แอปเปลี่ยน

**What to build:** ผู้ใช้กด Undo การ Apply ล่าสุดได้ Undo ย้อนเฉพาะรายการที่แอปเปลี่ยน รายการ PATH ที่โปรแกรมอื่นเพิ่มหลัง Apply ยังอยู่ ถ้าตัวแปรที่แอปเคยเขียนถูกแก้ทับไปแล้ว แอปแจ้ง conflict และให้ผู้ใช้เลือก

**Blocked by:** 03

**Status:** resolved

- [x] Undo หลังจากไม่มีการแก้อื่น ทำให้ registry ตรงกับก่อน Apply ทุกบรรทัด (U-1)
- [x] ตัวแปรแบบรายการ (PATH และตัวแปรที่คั่นด้วย `;`) เทียบทีละรายการ รายการที่โปรแกรมอื่นเพิ่มยังอยู่ (U-2)

- [x] รายการที่ย้อนไม่สำเร็จถูกรายงานทีละรายการ (U-4)
