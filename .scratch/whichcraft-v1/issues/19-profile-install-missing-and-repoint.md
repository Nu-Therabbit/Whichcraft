# 19: โปรไฟล์ — ติดตั้งตัวที่หาย และเปลี่ยนไปอ้างตัวใหม่

**What to build:** เมื่อโปรไฟล์อ้างถึงเวอร์ชันที่ไม่มีในเครื่อง แต่แอปติดตั้งให้ได้ ผู้ใช้กด "ติดตั้งตัวที่หาย แล้ว Apply ต่อ" ได้ และเมื่อผู้ใช้อัปเดตหรือถอนการติดตั้งที่มีโปรไฟล์อ้างถึง แอปเสนอให้เปลี่ยนโปรไฟล์ไปอ้างตัวใหม่
