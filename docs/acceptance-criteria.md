# Whichcraft — เกณฑ์ทดสอบรับงานรุ่นแรก

เกณฑ์ในเอกสารนี้มาจากการตัดสินใจใน [requirements.md](requirements.md) (Q1–Q29) และผลงานพิสูจน์ใน [spikes/](../spikes/) คำศัพท์ใช้ตาม [CONTEXT.md](../CONTEXT.md)

สร้างเมื่อ 23 ตุลาคม 2026

## หลักการทดสอบ

- **เครื่องทดสอบหลักคือเครื่องนี้** ใช้สภาพตามผลสำรวจในส่วนที่ 3 ของ requirements เช่น Temurin 4 ตัว, Node 24 ใน System PATH และ Flutter ที่ `E:\Dev\flutter`
- **ก่อนทดสอบทุกชุดที่เขียน registry** ให้สำรอง `HKCU\Environment` และ `HKLM\...\Session Manager\Environment` ด้วย `reg export` และหลังจบต้องเทียบได้ว่าไม่ต่างกันทุกบรรทัด ยกเว้นเกณฑ์ที่ตั้งใจให้ค่าคงอยู่
- **"process ใหม่ได้"** หมายถึงผลจากการรันด้วย environment ที่สร้างโดย `CreateEnvironmentBlock` แบบไม่สืบทอด (วิธีจาก [spike 1](../spikes/01-path/RESULT.md)) ไม่ใช่ environment ของ shell ที่ใช้ทดสอบ
- ทุกเกณฑ์ระบุที่มา และเกณฑ์ที่ทดสอบบนเครื่องนี้ไม่ได้ อยู่ในส่วนสุดท้าย

| A-6 | แอปถูกปิดกลาง Apply (kill process ระหว่างเขียน) | เปิดใหม่แล้วพบบันทึกที่ค้าง แสดงสถานะจริงของ registry และเสนอให้ทำต่อหรือย้อนกลับ | Q29, spike 4 (Envarly เก็บบันทึกในหน่วยความจำเท่านั้น) |

| A-8 | Apply สำเร็จ | มีการ broadcast `WM_SETTINGCHANGE` | spike 4 |
| A-9 | ระหว่างที่ผู้ใช้ดู diff หรือรอ UAC มีโปรแกรมอื่นเพิ่มรายการเข้า User PATH หรือแก้ตัวแปรที่อยู่ในแผน | ไม่เขียนอะไรเลย แสดงแผนและ diff ใหม่จากค่าปัจจุบันให้ยืนยันอีกครั้ง และรายการที่โปรแกรมอื่นเพิ่มยังอยู่ | รีวิว spec |
