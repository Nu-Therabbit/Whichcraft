# เริ่มจากค่าเริ่มต้นของ Windows ก่อนการแยกเวอร์ชันต่อโปรเจกต์

รุ่นแรกให้ผู้ใช้เลือกค่าเริ่มต้นของ Windows และเปิด Terminal ใหม่จากแอป การแยกเวอร์ชันต่อโปรเจกต์ที่เปิดพร้อมกันอยู่นอกขอบเขตรุ่นแรก การแยกต่อโปรเจกต์ทำให้ใช้หลายเวอร์ชันพร้อมกันได้ แต่ต้องเพิ่มงานส่งต่อ environment และเชื่อมกับ shell และ IDE เป้าหมายแรกคือให้การตรวจหา เลือก ดูการเปลี่ยนแปลง Apply และย้อนกลับของค่าเริ่มต้นใช้งานได้ครบก่อน

## Consequences

โปรแกรมที่เปิดอยู่แล้ว และ IDE ที่กำหนด SDK ของตัวเอง จะไม่เปลี่ยนตามค่าเริ่มต้นใหม่ แอปต้องแสดงข้อจำกัดนี้ให้ผู้ใช้เข้าใจ
