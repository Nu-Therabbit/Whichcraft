# ให้ native Git ตัดสินค่า config ไม่รันสิ่งที่ config สั่งตอนอ่าน และแยก journal ของไฟล์ config

หน้า Git config และ SSH ต้องอธิบายค่าที่มีผลใน repo หนึ่ง และแก้ไฟล์ config ของผู้ใช้โดยไม่ทำลายส่วนที่ไม่ได้แก้ เราจึงตัดสินสามข้อ:

- **native Git เป็นผู้ตัดสินค่าที่มีผล** ทั้งระดับที่โหลด include ที่ทำงาน ที่มาของค่า และค่าสุดท้าย แอปเรียก Git ที่เลือกไว้ใน repo นั้นเพื่ออ่านค่า และใช้ Git ประเมินสำเนาของไฟล์สำหรับ Impact Preview แอปไม่เขียน resolver ของ Git เอง เพราะกฎของ `includeIf`, path แบบ relative, worktree และ `safe.directory` มีรายละเอียดมาก และต่างกันตาม version
- **การเปิด รีเฟรช และ preview ไม่รันสิ่งที่ config สั่ง** แอปไม่เรียก pager, helper, alias, hook, filter, editor หรือ SSH จาก Git และไม่รัน `ssh -G` กับ config ของผู้ใช้ เพราะ `Match exec` สั่งรันคำสั่งได้ ฝั่ง SSH แอปจึง resolve เฉพาะส่วนที่ทำได้แบบ static และแสดงส่วนที่เหลือว่า unresolved ใช้ native SSH เทียบผลได้เฉพาะกับ fixture ที่ควบคุมเองและไม่มีเงื่อนไขที่รันคำสั่ง
- **การเขียนไฟล์ config มี journal ของตัวเอง** แยกจาก journal ของ Environment และเครื่องมือ บันทึกเฉพาะการแก้ครั้งนั้นก่อนเขียน Undo ย้อนเฉพาะการแก้ล่าสุดครั้งเดียว และหยุดถ้าตำแหน่งที่แก้ถูกเปลี่ยนหรือกำกวม journal เดิมเก็บค่าของตัวแปรใน registry ซึ่งย้อนทั้งค่าได้ แต่การย้อนไฟล์ต้องย้อนทีละช่วงเพื่อเก็บการแก้ของโปรแกรมอื่นไว้

## ผลที่ตามมา

- Git ที่เก่ากว่า 2.36 ใช้เงื่อนไข remote URL ไม่ได้ และที่เก่ากว่า 2.32 ทำ Impact Preview ไม่ได้ แอปซ่อนหรือติดป้ายส่วนนั้น แทนที่จะประมาณผลเอง
- ผลของ SSH config ที่มี `Match` แบบ dynamic จะไม่ครบ และแอปต้องบอกผู้ใช้ตรง ๆ
- โค้ด Undo และ recovery ของ Environment ใช้กับไฟล์ config ตรง ๆ ไม่ได้ แม้ UI จะทำตามแบบเดียวกัน

## Considered Options

- **เขียน resolver ของ Git เอง:** ไม่ต้องเรียก process และ preview ได้ทุกกรณี แต่จะได้ค่าที่ต่างจาก Git จริงในกรณีขอบ ซึ่งเป็นสิ่งที่หน้านี้ต้องอธิบายให้ถูก
- **ใช้ `ssh -G` อ่านค่าที่มีผลของ SSH:** ได้ผลครบที่สุด แต่รันคำสั่งจาก `Match exec` ของผู้ใช้ตอนแค่เปิดหน้า
- **ใช้ journal ของ Environment บันทึกไฟล์ทั้งไฟล์:** ทำเร็ว แต่การ Undo จะทับการแก้ของโปรแกรมอื่นที่เกิดหลัง Apply และ journal จะเก็บเนื้อหาไฟล์ที่ไม่เกี่ยวข้อง รวมถึงข้อมูลลับ
