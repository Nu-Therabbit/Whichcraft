# ส่ง CLI เป็น `bin\whichcraft.exe` และใส่เฉพาะโฟลเดอร์ `bin` ลง PATH

โปรแกรม console ของแอปเคยชื่อ `whichcraft.com` อยู่ข้าง GUI แล้วอาศัย PATHEXT ที่ลอง `.COM` ก่อน `.EXE` เมื่อทดสอบบนเครื่องจริง Bitdefender ติดป้าย `whichcraft.com --help` ว่าเป็นมัลแวร์ และลบแอปที่ติดตั้งออกทั้งชุด เพราะโปรแกรมที่ไม่มีลายเซ็นใน `AppData` ซึ่งถูกเรียกผ่าน PATH ด้วยนามสกุล `.com` เหมือนเทคนิคที่มัลแวร์ใช้ เราจึงย้าย CLI ไปเป็น `bin\whichcraft.exe` และให้แอปเพิ่มเฉพาะ `bin` ลง PATH เมื่อติดตั้งใหม่และรันขั้นตอนเดิมบนเครื่องเดียวกัน Bitdefender ไม่จับอีก แต่ผลนี้ยืนยันได้แค่เครื่องนั้น จึงยังควรเซ็นชื่อโค้ดก่อนปล่อย

## ผลที่ตามมา

- ห้ามกลับไปส่ง `.com` บน PATH
- CLI ชื่อไฟล์ตรงกับ GUI การหา GUI จึงต้องขึ้นไปโฟลเดอร์แม่ มิฉะนั้นจะเปิดตัวเอง
- สำเนาแบบ portable ไม่มี `bin` จึงใส่โฟลเดอร์ของตัวเองลง PATH
