# พาธในพื้นที่ของผู้ใช้เขียนลง User environment เท่านั้น

การติดตั้งที่แอปจัดการอยู่ใน `%LOCALAPPDATA%` ซึ่งเป็นพื้นที่ของผู้ใช้คนเดียว ถ้าเขียนพาธเหล่านี้ลง System PATH ผู้ใช้คนอื่นจะได้พาธที่เข้าไม่ได้ จึงกำหนดว่าพาธที่อยู่ในพื้นที่ของผู้ใช้ เขียนลง User environment เท่านั้น ถ้ามีรายการใน System PATH บังการติดตั้งที่เลือกอยู่ (เช่น `C:\Program Files\nodejs`) แอปจะเสนอให้เอารายการนั้นออกจาก System ผ่าน UAC และเตือนว่าผู้ใช้อื่นจะไม่มีเครื่องมือนั้นใน PATH แล้ว แทนที่จะเพิ่มพาธของผู้ใช้ลงใน System

## Considered Options

- **ที่เก็บแบบทั้งเครื่องที่ `C:\ProgramData\Whichcraft\installs`:** ต้องขอ UAC ตอนติดตั้ง และต้องดูแลที่เก็บสองแบบ ยังไม่คุ้มเพราะรุ่นแรกใช้คนเดียว จึงเลื่อนไปทำภายหลังถ้าต้องรองรับหลายผู้ใช้
