# เขียนพาธของการติดตั้งลง environment โดยตรง ไม่ใช้ shims ของ mise

แอปเขียนพาธของการติดตั้งที่ผู้ใช้เลือกลง environment ของ Windows โดยตรง เช่น PATH, JAVA_HOME และ GOROOT และใช้วิธีเดียวกันทั้งการติดตั้งภายนอกและการติดตั้งที่แอปจัดการ แอปไม่ใช้ `mise use -g` และไม่ใช้โฟลเดอร์ shims เหตุผลคือ diff และ Undo แสดงพาธจริงได้ ไม่ต้องลงทะเบียนการติดตั้งภายนอกเข้า mise และไม่เจอปัญหาของ shims บน Windows ได้แก่ การเลือกระหว่าง `.cmd` กับ `.exe` และ JAVA_HOME ที่ตั้งให้เฉพาะ process ที่เรียกผ่าน shim
